# עריכת רילס בקלוד קוד - Claude Code Skill

> **מבוסס על הפרומפטים של עדן ביבס (Brain AI).**
> כל פרומפט עריכה בסקיל הזה נכתב על ידי עדן, ופורסם בשני המדריכים שלו:
> - [הסרטון שערך את עצמו: כך עורכים וידאו בקלות עם Opus 5.5 בקלוד קוד](https://brainai.co.il/guides/claude-video-edited-itself)
> - [10 סגנונות עריכת וידאו שקלוד קוד יוצר לכם, פרומפט אחד לכל סגנון](https://brainai.co.il/guides/claude-video-editing-styles/)
>
> הסקיל לא משנה את הפרומפטים. הוא שומר את הסגנון שלך פעם אחת, ומריץ את הפרומפטים של עדן באותו סדר על כל קליפ.

צילמת קטע קצר, או חתכת אותו מסרטון ארוך. עכשיו צריך כתוביות, קצב, ורגע אחד שעוצר את הגלילה.

הסקיל הזה עושה את זה בתוך קלוד קוד, בלי תוכנת עריכה. **ואת הסגנון שלך אתה מגדיר רק פעם אחת.** מהקליפ השני והלאה כותבים "אותו סגנון".

---

## מה קורה כשמריצים

1. **בדיקת מצב** - איזה קליפים יש בתיקייה, ואם כבר שמרת סגנון.
2. **אשף סגנון (פעם אחת)** - פורמט, צבעים, פונט עברי, לוגו, מוזיקה, ו**אפקט חתימה אחד**. מה שכבר קיים אצלך (קובץ העסק, לוגו, פונט) נשאב לבד.
3. **חיתוך וכתוביות** - פרומפט הבסיס של עדן: מוריד שתיקות, מתמלל עם חותמת זמן לכל מילה, וכתוביות מונפשות בעברית.
4. **אפקט החתימה** - על המילה שבחרת מתוך טבלת המילים.
5. **סאונד ובדיקת עורך** - צליל לאפקט, ובדיקה של קלוד לפני שאתה רואה.

למה אפקט אחד? כי זו ההמלצה של עדן: "בחרו סגנון אחד שמתאים למסר, תנו לו להוביל... ככה הוא הופך לסגנון שלכם, ולא לעוד אפקט."

---

## מה צריך

1. **Claude Code** עם מנוי בתשלום (Pro מספיק).
2. **מודל Opus 5.5** - עדן בנה ובדק את הפרומפטים רק עליו.
3. **מחשב מק או ווינדוס.** הרינדור קורה אצלך, ולא עולה כסף. במחשב חלש הוא פשוט ייקח יותר זמן.
4. **קליפ שבו אתה מדבר למצלמה.** כל צילום מהטלפון עובד.
5. רשות: קובץ פונט עברי, לוגו, ומוזיקה שיש לך זכויות עליה.

הכלים בדרך (Python, ffmpeg, Node.js, HyperFrames, מודל התמלול של ivrit.ai) חינמיים. קלוד מתקין אותם בעצמו ומבקש אישור.

## התקנה ושימוש

1. פותחים Claude Code בתיקייה שבה הקליפים.
2. מדביקים את הלינק לריפו וכותבים: **"תתקין לי את הסקיל שנמצא כאן בפרויקט הנוכחי"**
3. כותבים: **"תערוך לי את הקליפ לריל"**

ומשם:

```
תעבור על כל הקליפים בתיקייה באותו סגנון
תזיז את האפקט למילה "עכשיו"
הכתוביות מכסות לי את הפנים, תזיז אותן למטה
```

## מה הסקיל לא עושה

- **לא מעלה לרשתות** ולא כותב כיתוב לפוסט.
- **לא יודע מה יהפוך לוויראלי.** כמו שעדן כותב: "אפקט טוב עוצר את הגלילה לרגע, ומה שמחזיק את הצופים הוא מה שאתם אומרים."
- **לא מוצא את הרגעים בסרטון ארוך.** בשביל זה יש את ההדרכה הקודמת במועדון, על חיתוך סרטון ארוך לקטעים.
- **לא ממציא תוכן.** קיר תגובות נבנה רק מתגובות אמיתיות שתשים בקובץ.
